# Тренажёр дилера

Vanilla JS/PWA-приложение для тренировок дилера: умножение, сложение, Blackjack, счёт фишек, выплаты, покер, дуэль и справочник.

## Запуск

Откройте проект через локальный HTTP-сервер, чтобы работали Service Worker и PWA:

```powershell
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Структура

- `index.html` — разметка вкладок и справочника.
- `js/modes/` — отдельные тренировочные режимы.
- `js/utils.js` — DOM-хелперы, безопасное хранилище и общие функции.
- `js/stats.js` — постоянная статистика по режимам.
- `js/settings.js` — настройки и миграция локальных данных.
- `sw.js` — offline-кэш PWA.

## Данные

Настройки и статистика хранятся локально в браузере. Смена устройства или очистка site data удалит их. Настройки предыдущего формата мигрируют автоматически.

## Дуэль

Дуэль использует публичные MQTT-брокеры и предназначена для тренировок, а не для приватных или защищённых данных. Для работы нужен интернет.

## Проверки

Проверка синтаксиса всех JavaScript-файлов:

```powershell
Get-ChildItem -Recurse -Filter *.js | ForEach-Object { node --check $_.FullName }
```

Проверка ссылок и ID:

```powershell
node tests/smoke.mjs
```

## Добавление выплат

Для новых покерных правил обновляйте каталог в `js/modes/poker.js` и соответствующую секцию справочника в `index.html`. Коэффициенты должны быть проверены по layout конкретного стола.
